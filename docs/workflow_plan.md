# HRD 웹페이지 작업 진행 단계 (Workflow Plan)

이 문서는 한 달 단기 홍보용 랜딩 페이지를 빠르고 효율적으로 구축하기 위한 작업 단계입니다.

## Step 1: 기획 및 환경 설정
- [ ] 문서화된 기획서(docs/prompt_spec.md) 확인 및 샘플 컨셉(A/B/C) 중 최종 1안 선택
- [ ] 개발 환경 세팅 (Next.js 또는 Vite 기반 + TailwindCSS/순수 CSS 설정 선택)
- [ ] 프로젝트 폴더 구조 설계 및 초기화

## Step 2: 트래킹 도구 및 뼈대 연동
- [ ] Google Analytics 4 (GA4) 태그 스크립트 셋업 (시간별 접속자 파악용)
- [ ] SEO 최적화를 위한 메타 태그(Title, Description, Open Graph) 설정
- [ ] Header(로고/네비게이션) 및 Footer 공통 컴포넌트 구현

## Step 3: 메인 섹션 UI 개발
- [ ] **Hero 섹션**: 메인 카피(타이틀), 서브 카피, CTA(Call to Action - 구글폼 이동 버튼)
- [ ] **About 섹션**: AI 스마트팩토리 교육 과정 개요 및 목표 소개
- [ ] **Benefits 섹션**: 훈련 수당, 기숙사, 포트폴리오 등 혜택을 카드 UI로 구성
- [ ] **Curriculum & Career 섹션**: 교육 과정 및 수료 후 진로 방향 타임라인/아이콘 뷰 구축

## Step 4: 구글폼 연동 및 기능 구현
- [ ] 각 섹션에 위치한 '수강신청' 버튼 클릭 시 제공된 구글폼 URL로 새 창 열기 연결
- [ ] 구글폼 클릭 이벤트를 GA4에 전송하여 전환(Conversion) 데이터 수집 설정

## Step 5: 디자인 폴리싱 및 반응형 최적화
- [ ] 데스크탑, 태블릿, 모바일 기기에 맞춘 반응형(Responsive) 레이아웃 적용
- [ ] 과하지 않고 고급스러운 마이크로 애니메이션(호버 효과, 페이드인 등) 추가
- [ ] 기존 전달된 자료의 가독성 저하 문제를 해결하기 위한 타이포그래피/여백 조정

## Step 6: 검수(QA) 및 런칭
- [ ] 크로스 브라우징 및 모바일 실기기 화면 테스트
- [ ] 단기 운영에 적합한 플랫폼(Vercel, Netlify 등)을 이용한 웹페이지 배포
- [ ] GA4 실시간 트래픽 집계 정상 작동 여부 확인
