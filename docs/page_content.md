## 4. 상세 커리큘럼
### [트랙 1] 스마트팩토리 과정 커리큘럼
![스마트팩토리 과정 커리큘럼](/sf_curriculum.png)
**① 자동화 설비 이해**: PLC 기초 및 자동화 설비 제어, 센서 및 장비 구조 및 생산 공정 흐름 이해, 자동화설비 관련 자격증 취득
**② 데이터 수집·분석**: IoT 센서 데이터 수집, 장비 데이터 모니터링, 생산 데이터 분석 기초
**③ 스마트 공정 구현**: 스마트팩토리 디지털 트윈, 공정 모니터링 및 MES 시스템 화면 조작, 스마트 공정 구현 팀 프로젝트

### [트랙 2] AI+데이터 분석 실무 커리큘럼
![AI+데이터 분석 실무 커리큘럼](/ai_curriculum.png)
**① 데이터 분석 기초**: 제조 데이터 구조 이해 및 데이터 분석 기초 학습, SQL 기반 데이터 조회 및 데이터베이스 활용, Python을 활용한 데이터 탐색 및 시각화 실습
**② AI 모델 개발**: Python 기반 머신러닝 알고리즘 학습, 회귀·분류 모델을 활용한 데이터 분석 실습, 딥러닝 기반 AI 모델 구축 및 활용
**③ 제조 데이터 AI 프로젝트**: 제조 공정 데이터 활용 데이터 분석 프로젝트, AI 모델을 활용한 공정 문제 해결 실습, 데이터 분석 관련 자격증 취득
